
# 🧮 Arbitrary Precision Calculator (APC)

## 📌 Description

A **C-based Arbitrary Precision Calculator** that performs arithmetic operations on **very large numbers** that cannot be handled by standard integer data types. The project uses **doubly linked lists** to store and process each digit efficiently.

## ✨ Features

* ➕ Addition of large numbers
* ➖ Subtraction of large numbers
* ✖️ Multiplication of large numbers
* ➗ Division of large numbers
* 🔢 Supports numbers beyond standard data type limits
* 🔗 Uses doubly linked lists for digit storage
* ⚙️ Handles carry and borrow operations
* 💻 Implemented completely in C

## 🛠️ Technologies Used

* 💻 C Programming
* 🔗 Doubly Linked Lists
* 📂 Dynamic Memory Allocation
* 👉 Pointers
* 🔢 Arithmetic Operations
* ⚙️ Command Line Arguments

## 🎯 Objective

To implement arithmetic operations on **arbitrarily large numbers** using data structures and overcome the limitations of standard C integer data types.

## 🚀 How It Works

### 🔢 Number Representation

Each digit of a large number is stored as a **node in a doubly linked list**.

### ➕ Arithmetic Operations

The calculator performs operations such as addition, subtraction, multiplication, and division by processing the digits stored in the linked lists.

### ⚙️ Carry & Borrow

Carry and borrow are handled during arithmetic operations to produce the correct result for large numbers.
